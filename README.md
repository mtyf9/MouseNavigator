# MouseNavigator

让常用操作跟随鼠标。按住鼠标中键，向一个方向移动，松开即可切换窗口或执行快捷键。

MouseNavigator 支持为不同应用设置不同的环形菜单。例如，在编辑器中快速保存，在其他应用中切换窗口或打开任务视图。

## 运行要求与启动

- Windows 11，64 位 x64 电脑。
- .NET 10 桌面运行时；如果启动时提示缺少运行时，请先安装对应的 x64 版本。
- 将完整程序文件夹保存在电脑上，运行其中的 MouseNavigator.App.exe。请勿只复制单个 exe 文件。

启动后默认启用中键操作。主界面开关可以暂停或恢复；需要在后台使用时，将主窗口最小化。关闭主窗口会退出软件。

## 基本操作

1. 在需要操作的应用中，按住鼠标中键（滚轮按键）。
2. 稍微移动鼠标，唤出环形菜单。
3. 保持按住，把鼠标移到想执行的按钮。
4. 松开中键，执行当前选中的操作。

**取消操作：**把鼠标移回中心或移出菜单后松开，或者直接按 Esc。按住期间经过中心、移出菜单都不会自动关闭，可以继续选择。

轻点中键仍会传递普通中键点击，例如浏览器中的中键打开链接。软件启用时不保留应用原生的“按住中键拖动”行为；需要该行为时，请在主界面暂停。

## 默认菜单

| 方向 | 操作 |
| --- | --- |
| 上方 | 窗口预览：移入展开，选中缩略图后松开切换 |
| 右侧 | 最大化窗口 |
| 下方 | 最小化所有窗口 |
| 左侧 | 打开 Windows 任务视图 |

文件资源管理器有独立的默认菜单，上方是“最大化窗口”，右侧是“窗口预览”。

窗口切换范围为当前虚拟桌面，包含各显示器上的窗口和最小化窗口；切回最小化窗口时会恢复显示。通过窗口预览直接选择目标，**不跟随任务栏排列**。

## 从缩略图选择窗口

1. 按住中键并稍微移动，唤出菜单。
2. 保持按住，移入“窗口预览”按钮，展开缩略图面板。
3. 继续移动到目标窗口，蓝色边框表示当前选中。
4. 松开中键，切换到该窗口；最小化的窗口会恢复显示。

面板刚展开时不会自动选中窗口，需要继续移动后才会高亮。在空白处或面板外松开，或者按 Esc，均可取消。保持按住时移出面板不会关闭，仍可移回选择。

窗口较多时，把鼠标停留在底部“上一页”或“下一页”约 0.65 秒即可翻页。每次打开面板后卡片位置保持不变，途中关闭的窗口会变暗，避免其他卡片移位造成误选。新打开的窗口在下次展开时显示。

预览范围是当前虚拟桌面的应用窗口，包含其他显示器上的窗口。部分窗口可能无法提供缩略图，此时仍可根据标题选择。面板不按照任务栏顺序排列。

**已有配置的用户：**更新不会覆盖原菜单。请到“悬浮窗菜单”选择需要修改的按钮，把“动作”改为“窗口预览”，再点击“保存并应用”。“任务视图”仍是单独的操作，用于打开 Windows 自带任务视图。

## 自定义菜单

打开主界面的“悬浮窗菜单”：

1. 选择要修改的菜单。
2. 点击环形预览中的一个按钮。
3. 在“动作”中选择内置操作、自定义快捷键或“不执行动作”。
4. 点击“保存并应用”。

内置操作包括窗口预览、任务视图、最大化窗口、全部最小化和左右切换虚拟桌面。未保存的修改只保留在编辑草稿中，不影响正在使用的菜单。

### 用拖拽设计菜单

左侧是预设按钮，中间是悬浮菜单，右侧是“配置按钮”。编辑预览和实际菜单共用同一个控件，并按相同大小显示。空间不足时，可在编辑区滚动查看轮盘。

- 从左侧预设拖入某一圈，松开即可添加一个独立按钮。
- 把菜单内的按钮拖到目标位置，按钮会跟随鼠标，其他按钮平滑让出位置。松开后按新顺序排列，也可以跨圈移动，或移到空圈。
- 点击预览右下角的垃圾桶，或把按钮拖到垃圾桶图标后松开，会弹出删除确认。在轮盘外其他位置松开、按 Esc 或取消删除，都会保留原布局。
- 点击按钮，在右侧修改名称、动作、快捷键和图标。删除操作统一使用右下角垃圾桶。
- 预设列表的第一项是“空白按钮”，拖入后可自行配置。
- 点击左下角“保存为预设按钮”，或把菜单按钮拖到该图标，把当前名称、图标与动作存成新的侧边预设。之后修改菜单按钮不会影响预设，修改其他副本也不会相互影响。

自定义预设可右键删除。添加到菜单的按钮仍会保留。

### 添加和删除圈

打开预览下方居中的“第 X 圈”下拉框，首项“＋内圈”会在最内侧插入空圈，原有圈向外移动；选择末项“＋外圈”可连续向外围添加圈，每圈可放置最多 12 个按钮。在圈下拉框选择要删除的圈，再点击“删除圈”；圈内有按钮时会先确认。删除内圈后，其余圈按顺序向内收拢。可以删空所有圈，再重新添加。

选中一圈后，点击预览左上角“逆时针旋转”、右上角“顺时针旋转”的环形箭头。每次旋转 180° ÷ 该圈按钮数量，也就是半个按钮的角度；两按钮布局可由上下改为左右，奇数按钮也能改变朝向。旋转会保存，实际菜单与编辑预览一致。旋转过的圈在插入、删除按钮后，会向前一个有效角度对齐，让至少一条按钮分界线保持水平或垂直；同圈排序不会改变角度。跨圈移动会分别对齐按钮数量变化的圈。

在两侧旋转按钮之间的“悬浮窗大小”滑块中可调整当前菜单到 50%～200%，预览随拖动实时变化。点击“保存并应用”后，实际悬浮窗使用该大小；每个菜单可单独设置，导入导出时也会保留。编辑区不会为适应栏目宽度缩小菜单。较大的菜单会适配当前屏幕工作区，同一显示器上的编辑预览和实际菜单尺寸一致。多圈菜单中，在“窗口预览”按钮上停留约 0.25 秒才展开缩略图，便于穿过内圈选择外圈按钮。

### 图标与图片

在“配置按钮”中点击“选择图标 / 图片”，从图标网格中选择，也可使用“跟随动作”。点击“选择图片…”可选择 PNG、JPEG、BMP 或 ICO 文件。图片会缩为小图标并内嵌保存，移动原图片或将菜单配置分享给别人都不会丢失图标。

修改只影响当前菜单按钮；要复用修改后的样式，请保存为新预设。

### 轮盘中心

点击轮盘中心的“松开执行”（或当前中心文字/图片），右侧“配置按钮”会切换到中心按钮配置，可以自定义文字，选择预设图标或图片，也可以移除图标。点击外围按钮即可回到对应按钮的配置。每个悬浮菜单独立设置，编辑预览和实际使用时显示相同内容。图片会内嵌在配置中，一起保存和分享。

文字留空时不显示文字，可以只显示图标或图片。“恢复默认中心”会移除自定义图标和图片，并恢复默认提示（“取消”“进入预览”或“松开执行”）。中心始终是取消区域，自定义外观不会改变松开中键的行为。修改后点击顶部“保存并应用”。

### 菜单管理

- 在顶部菜单下拉框选择“＋新建悬浮菜单”，输入名称创建。
- 使用“重命名”弹窗修改当前菜单名称。
- “保存并应用”“放弃修改”“恢复默认”集中在顶部。“恢复默认”重置菜单，保留个人预设按钮。
- “应用匹配”直接显示。点击“选择应用程序…”从文件选择器选取一个或多个 EXE，也可手动输入进程名。
- 每个菜单都有启用开关；禁用菜单不参与匹配。未匹配到已启用的专属菜单时使用全局默认菜单；默认菜单也被禁用时不显示悬浮窗。
- 在“应用匹配”旁勾选“设为全局默认菜单”，会自动取消原菜单的默认标记，始终只有一个默认菜单。原菜单的应用绑定仍会保留。删除默认菜单前，请先指定其他菜单为默认。
- “删除菜单”旁的“导入菜单／导出菜单”用于单个菜单，包含其按钮、图片、快捷键、旋转、大小和启用状态。同名导入可选“覆盖”或“另存”；另存自动加 +1、+2。新增导入不会自动替换默认菜单，覆盖时保留被覆盖菜单的默认身份。

旧版四方向及单圈配置会自动迁移到内圈，保留名称、图标、快捷键和原有顺序。保存或导出后使用新版格式，旧版本程序无法读取，请保留原备份以便回退。
### 设置快捷键

选择“自定义快捷键”后：

- 填写易于识别的显示名称，例如“保存文件”。
- 点击“录入快捷键”，按下完整组合后全部松开。录入期间会临时拦截普通系统快捷键，完成、失焦、取消或超时后自动停止。也可以勾选 Ctrl、Alt、Shift、Win，再从列表选择主键。
- 确认显示的组合正确，点击“保存并应用”。

例如，将右侧设置为“保存文件 / Ctrl + S”，以后在目标应用中向右选择并松开中键，就会向该应用发送 Ctrl+S。快捷键的实际效果取决于目标应用。

支持字母、数字、F1–F24、常用导航键和标点键。录入时按 Esc 退出；要设置 Esc 本身，请使用主键列表。Ctrl+Alt+Del 等安全组合无法拦截录入，请用修饰键和主键选择器配置；配置成功也不代表 Windows 允许程序模拟该安全组合。

### 为不同应用设置菜单

在顶部下拉框选择“＋新建悬浮菜单”，输入名称；随后在“应用匹配”中选择 EXE，或填写实际进程名，例如：

| 应用 | 进程名示例 |
| --- | --- |
| Visual Studio Code | Code.exe |
| Visual Studio | devenv.exe |
| 文件资源管理器 | explorer.exe |

可以填写多个进程名，用分号分隔，例如 Code.exe; devenv.exe。名称不区分大小写，可省略 .exe，不填写完整文件路径。

唤出菜单时，软件会识别当时的应用。没有专属匹配时使用勾选的全局默认菜单。新菜单未绑定应用时暂不参与自动匹配。多个启用菜单可以填入同一个进程，因此可能冲突；界面会提示重复匹配，优先级数值高的生效，同级时按菜单标识固定选择。

## 保存、备份与分享

- **保存并应用：**保存全部菜单，下次触发立即使用新设置；重启后自动加载。
- **备份配置（主界面）：**将当前全部菜单、快捷键、图片图标和个人预设保存为文件，也包含尚未保存的菜单编辑。
- **还原配置（主界面）：**选择备份文件并确认后，替换现有全部配置及未保存编辑，自动保存并立即生效。取消或文件无效时保留现有配置。
- **放弃修改：**回到最近保存的状态。
- **恢复默认：**将默认菜单载入草稿，保存后生效。

可以导入仓库中的 [示例菜单](examples/menus.example.json)，体验编辑器专属的 Ctrl+S 操作。

个人设置保存在：

    %LOCALAPPDATA%\MouseNavigator\settings.json

上一份有效配置保存在同目录的 settings.json.bak。配置无法读取时，软件会尝试使用备份并显示提示；没有可用备份时暂用默认菜单，不会在启动时覆盖原文件。

还原全部配置会替换现有配置，建议先备份需要保留的修改。单菜单分享仍可使用“悬浮窗菜单”页面的“导入菜单 / 导出菜单”。收到他人分享的配置后，可以在界面中检查各按钮绑定的操作；不可用的动作会显示提示。

## 开机启动与托盘

在主界面打开“开机启动”，下次登录 Windows 后自动运行并驻留托盘，不弹出主窗口；关闭开关可取消。此设置只作用于当前 Windows 用户和当前程序位置，不包含在菜单备份中。移动程序目录后，请重新开启开机启动；如果在 Windows 的“启动应用”中禁用过本程序，也需要在那里重新启用。

程序提供统一的任务栏和通知区域图标。首次关闭主窗口会提示最小化到托盘，勾选“不再提示”并确认后，下次关闭及重启后都不再提示；取消不会隐藏窗口或保存该选择。关闭主窗口后仍在后台运行，未保存的菜单编辑会保留：
- 点击托盘图标或重新打开程序，可恢复主界面。
- 右键托盘图标可打开主界面、暂停/启用悬浮导航，或退出程序。
- 从托盘退出时，若有未保存的菜单修改，会提示保存、放弃或继续编辑。

## 常见问题

**按住中键没有弹出菜单？**

确认主界面开关已启用，并在按住时稍微移动鼠标。仅按下但没有拖动，不会显示菜单。

**快捷键没有生效？**

确认已保存配置，并检查目标应用是否支持该快捷键。松开键盘上的 Ctrl、Alt、Shift、Win 后再尝试。权限更高的应用可能拒绝接收快捷键，主界面会显示执行结果。

**为什么窗口顺序和任务栏不一样？**

窗口预览不读取任务栏顺序，打开后会固定本次选择的卡片位置。旧配置中的“上一个／下一个窗口”会自动转换为“窗口预览”。

**菜单改错了怎么办？**

尚未保存时点击“放弃修改”；需要重新开始时点击“恢复默认”并保存。也可以导入此前导出的备份。

**关闭窗口后为什么不能继续使用？**

关闭主窗口会退出软件。当前需要通过最小化主窗口保持运行。
